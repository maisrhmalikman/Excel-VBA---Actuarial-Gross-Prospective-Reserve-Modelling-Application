# Excel-VBA---Actuarial-Gross-Prospective-Reserve-Modelling-Application

Actuarial reserve calculations can involve repetitive calculations over multiple policy years, particularly when calculating survival probabilities. This project was developed to automate these calculations and reduce the potential for manual calculation errors while providing a more flexible approach to valuing different life insurance products. 

AM92 mortality table was used in this project for easier educational calculation checking and validation. Users can input benefit, premium, and expense assumptions through an interactive Excel VBA UserForm. The details and calculated reserve table will be displayed on the Dashboard sheet. Users can also visualise the reserve schedule through a graph and print the results directly from the application.

Tools: Microsoft Excel, VBA, Power Query for data preparation and processing

Life insurances products include:
1.	Whole Life Assurance
2.	Term Assurance
3.	Pure Endowment Assurance
4.	Endowment Assurance
5.	Whole Life Annuity (Due & Immediate)
6.	Temporary Life Annuity (Due & Immediate)
